# Оплаты — учёт по способам оплаты

Веб-приложение для подсчёта оплат клиентов. Вводишь сумму, выбираешь способ оплаты —
запись сохраняется с точным временем. Дальше приложение показывает графики по дням,
суммы по каждому способу, отдельно безналичные (QR + Карта) и общий итог.

Работает как обычный сайт и как приложение на домашнем экране iPhone/Android.
**Все данные хранятся только на устройстве** — в `localStorage` браузера. Ни один
платёж не отправляется в сеть, серверная часть отсутствует.

## Возможности

- **Ввод суммы** большой цифровой клавиатурой, с копейками (`1500,50`).
- **Три способа оплаты**: Безнал — QR, Безнал — Картой, Наличными.
- **Уведомление «Сохранено»** со способом, суммой и временем записи.
- **График по дням** — столбец на день, цветные слои по способам, подпись итога.
  Тап по столбцу открывает детали дня.
- **Итоги за 7 / 14 / 30 дней**: по каждому способу, безнал (QR + Карта),
  общая сумма, количество оплат и средний чек.
- **История** всех операций с временем, удалением записей.
- **Экспорт CSV** (открывается в Excel) и **резервная копия JSON** с восстановлением.
- **Офлайн-режим**: после первого открытия работает без интернета.

## Технологии

Ноль зависимостей и ноль сборки: нативные ES-модули, CSS и SVG-графики,
нарисованные вручную. Поэтому файлы можно выложить на GitHub Pages как есть —
ни `npm install`, ни CI не нужны.

## Локальный запуск

Модули требуют http-протокола, открыть `index.html` двойным щелчком не получится.
Поднимите любой локальный сервер, например встроенный в Python:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой публичный репозиторий, например `payments-counter`.
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "Приложение для учёта оплат"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/payments-counter.git
git push -u origin main
```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите Source: **Deploy from a branch**,
   Branch: **main**, папка: **/ (root)**. Нажмите **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу
   `https://ВАШ_ЛОГИН.github.io/payments-counter/`.

Все пути в проекте относительные, поэтому подпапка в адресе работает корректно.

## Иконка на домашнем экране iPhone

1. Откройте адрес приложения **в Safari** (в других браузерах iOS не даёт добавлять на экран).
2. Кнопка «Поделиться» → **На экран «Домой»** → **Добавить**.
3. Запускайте с домашнего экрана: приложение откроется без адресной строки,
   как обычное приложение, и будет работать офлайн.

## Важно про сохранность данных

Данные лежат в хранилище браузера. Они исчезнут, если очистить данные сайта в Safari,
удалить иконку вместе с данными или сменить устройство. Поэтому:

- периодически нажимайте **«Резервная копия»** на вкладке «История» — файл JSON
  можно сохранить в «Файлы» или отправить себе;
- восстановление — кнопка **«Восстановить»** и тот же файл.

## Структура проекта

```
index.html               каркас: шапка, контейнер экрана, таб-бар
manifest.webmanifest     описание PWA для установки на домашний экран
sw.js                    service worker: офлайн-кэш оболочки
css/styles.css           стили и токены, светлая и тёмная темы
js/app.js                запуск, переключение вкладок, шапка
js/store.js              хранилище платежей в localStorage
js/analytics.js          работа с датами и агрегация сумм
js/money.js              копейки, форматирование, ввод с клавиатуры
js/methods.js            описание способов оплаты
js/export.js             CSV и резервные копии JSON
js/components/           график, плитки итогов, тосты, DOM-хелперы
js/views/                экраны: ввод, статистика, история
tools/make_icons.py      генерация PNG-иконок из чистого Python
```

## Обновление опубликованной версии

Service worker кэширует оболочку приложения. После изменения кода поднимите
`CACHE_VERSION` в `sw.js` — иначе на телефоне останется предыдущая версия.

## Суммы и деньги

Внутри приложения все суммы — целое число копеек. Это исключает ошибки округления,
неизбежные при подсчёте денег числами с плавающей точкой.

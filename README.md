# Оплаты — учёт по способам оплаты

Веб-приложение для подсчёта оплат клиентов. Вводишь сумму, выбираешь способ оплаты —
запись уходит в Google Таблицу с точным временем. Приложение показывает графики по дням,
суммы по каждому способу, отдельно безналичные (QR + Карта) и общий итог.

Работает как обычный сайт и как приложение на домашнем экране iPhone/Android.
Хостится бесплатно на GitHub Pages, серверная часть не нужна.

## Где живут данные

Единственное место хранения — **Google Таблица** в твоём Google Диске. На устройстве
ничего не сохраняется: приложение читает таблицу при открытии и пишет в неё при каждой
записи. Открыл на телефоне, открыл на компьютере — видишь одни и те же данные.

Обратная сторона: **без интернета приложение не работает**. Внести оплату при
отсутствии связи не получится, будет показана ошибка с кнопкой «Повторить».

## Как это устроено

Между приложением и таблицей стоит скрипт Google Apps Script, который живёт внутри
самой таблицы и опубликован как веб-приложение. Приложение обращается к нему по HTTP,
поэтому входить в Google на телефоне не нужно.

```
Приложение (GitHub Pages) ──HTTP──► Apps Script ──► Google Таблица
```

### Важное предупреждение о безопасности

Адрес скрипта и токен лежат в файле `js/config.js`, а код на GitHub Pages публичный.
Любой, кто найдёт эти два значения, сможет читать и писать в твою таблицу. Для личного
счётчика оплат это обычно приемлемо, но помни об этом. Что можно сделать:

- взять длинный случайный токен, а не осмысленное слово;
- если токен утёк — поменять его в `Code.gs` и в `config.js`, переразвернуть скрипт;
- если нужна настоящая защита — репозиторий придётся сделать приватным
  (GitHub Pages для приватных репозиториев требует платного тарифа) либо переходить
  на схему с входом в Google через OAuth.

## Настройка (делается один раз)

### 1. Таблица и скрипт

1. Создай новую Google Таблицу.
2. В ней: **Расширения → Apps Script**.
3. Удали содержимое редактора и вставь код из файла `apps-script/Code.gs`.
4. Замени константу `TOKEN` на свою случайную строку, например
   `k7Qm-2vX9-pLd4-Rt81`.
5. Сохрани проект, выбери в списке функций `setup` и нажми **Выполнить**.
   Google попросит разрешения — выдай их. Скрипт создаст лист «Оплаты» с заголовками.

### 2. Публикация скрипта

1. **Развёртывание → Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. «Запуск от имени» — **я**.
4. «Кто имеет доступ» — **все** (без этого браузер не сможет обратиться к скрипту).
5. Скопируй адрес развёртывания — он оканчивается на `/exec`.

### 3. Подключение приложения

Открой `js/config.js` и заполни:

```js
export const SHEET_API = {
  url: 'https://script.google.com/macros/s/AKfy.../exec',
  token: 'k7Qm-2vX9-pLd4-Rt81',
  sheetUrl: 'https://docs.google.com/spreadsheets/d/.../edit',
};
```

`sheetUrl` необязателен — он нужен только для кнопки «Открыть таблицу».

Пока `url` и `token` пустые, приложение показывает экран настройки вместо рабочих
экранов, поэтому «сломанным» оно не выглядит.

> После **любого** изменения `Code.gs` нужно заново выпустить развёртывание
> (**Развёртывание → Управление развёртываниями → Изменить → Новая версия**),
> иначе по прежнему адресу продолжит отвечать старая версия скрипта.

## Структура листа «Оплаты»

| Колонка | Назначение |
| --- | --- |
| ID | Идентификатор записи, по нему работает удаление |
| Дата | `дд.мм.гггг` для чтения глазами |
| Время | `чч:мм` для чтения глазами |
| Способ оплаты | Название способа |
| Код | Служебный код: `qr`, `card`, `cash` |
| Тип | «Безналичная» или «Наличные» |
| Сумма | Число в рублях — по нему удобно строить сводные таблицы |
| Метка времени | Точное время в формате ISO, основной источник для приложения |

Строки можно добавлять и в самой таблице руками. Достаточно заполнить **Дату**,
**Время**, **Способ оплаты** и **Сумму** — остальные колонки скрипт заполнит сам при
следующем обращении приложения. Изменения, внесённые в таблице, появятся в приложении
после нажатия кнопки обновления.

Порядок и названия колонок менять нельзя — скрипт обращается к ним по позиции.

## Возможности

- **Ввод суммы** большой цифровой клавиатурой, с копейками (`1500,50`).
- **Три способа оплаты**: Безнал — QR, Безнал — Картой, Наличными.
- **Уведомление «Сохранено»** появляется только после подтверждения от таблицы.
  Если запись не ушла, введённая сумма остаётся на экране — можно повторить.
- **График по дням** — столбец на день, цветные слои по способам, подпись итога.
  Тап по столбцу открывает детали дня.
- **Итоги за 7 / 14 / 30 дней**: по каждому способу, безнал (QR + Карта),
  общая сумма, количество оплат и средний чек.
- **История** всех операций с временем; удаление убирает строку и из таблицы.
- **Полоса состояния** под шапкой честно показывает чтение таблицы и ошибки связи.

## Технологии

Ноль зависимостей и ноль сборки: нативные ES-модули, CSS и SVG-графики, нарисованные
вручную. Файлы выкладываются на GitHub Pages как есть — ни `npm install`, ни CI не нужны.

## Публикация на GitHub Pages

1. Создай на GitHub репозиторий, например `payments-counter`.
2. В папке проекта выполни:

```bash
git init
git add .
git commit -m "Приложение для учёта оплат"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/payments-counter.git
git push -u origin main
```

3. В репозитории: **Settings → Pages**.
4. Source: **Deploy from a branch**, Branch: **main**, папка: **/ (root)**. Сохрани.
5. Через 1–2 минуты приложение будет доступно по адресу
   `https://ВАШ_ЛОГИН.github.io/payments-counter/`.

Все пути в проекте относительные, поэтому подпапка в адресе работает корректно.

## Иконка на домашнем экране iPhone

1. Открой адрес приложения **в Safari** (в других браузерах iOS не даёт добавлять на экран).
2. Кнопка «Поделиться» → **На экран «Домой»** → **Добавить**.
3. Запускай с домашнего экрана: приложение откроется без адресной строки.

## Локальная разработка

Модули требуют http-протокола, открыть `index.html` двойным щелчком не получится.

```bash
python -m http.server 8000
```

Чтобы проверять приложение, не трогая настоящую таблицу, есть заглушка с тем же
протоколом. Она хранит записи в файле рядом с собой:

```bash
python tools/mock_sheet_server.py
```

Затем временно укажи в `js/config.js` адрес `http://localhost:8765/` и токен
`dev-token`. Перед публикацией не забудь вернуть настоящие значения.

## Обновление опубликованной версии

Service worker кэширует оболочку приложения. После изменения кода подними
`CACHE_VERSION` в `sw.js` — иначе на телефоне останется предыдущая версия.

## Суммы и деньги

Внутри приложения все суммы — целое число копеек. Это исключает ошибки округления,
неизбежные при подсчёте денег числами с плавающей точкой. В таблицу сумма пишется
в рублях, чтобы по колонке можно было считать формулами.
